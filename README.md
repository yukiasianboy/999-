# 九九九救護車（999）預約原型

## 開啟介面

Windows 解壓縮後，雙擊 `開啟九九九救護車.bat`，以預設瀏覽器開啟網頁。Mac 或 Linux 可用瀏覽器開啟 `index.html`。請勿以文字編輯器或 GitHub 檔案檢視器開啟 HTML，否則會看到原始碼。

若要放到 GitHub Pages，將 `index.html` 放在儲存庫根目錄，再於儲存庫設定中啟用 Pages。GitHub 的一般檔案頁面會顯示原始碼；Pages 網站才會呈現應用介面。

## 功能

- 民間救護車預約表單、服務類型及醫療需求選擇
- 醫院搜尋、院內樓層與病室欄位
- 依起訖地點估算駕車里程與時間
- 依目前設定的費率逐項試算費用

## 外部服務與資料

地點搜尋使用 Photon 公開示範服務，路線里程使用 OSRM 公開路線服務。搜尋時輸入的地點會傳送給相應服務；公開服務可能限流或暫時無法使用。

這是展示原型，尚未串接後端、正式派車或儲存預約資料。不要在公開展示版本輸入真實病患資料。跨縣市費率與路程須由服務人員確認。
